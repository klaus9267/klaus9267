## About Me

- 🧑‍💻 인덱스, 쿼리 튜닝 등을 통해 캐싱 없이 **조회 성능을 94% 개선**(8.28s → 0.481s 100만 건 기준)한 경험이 있습니다.
- ⚙️ AWS기반 Cloud Server 구축을 경험했으며 **Mini PC기반 On-Premise Server를 구축 및 운영**하고 있습니다.
- 🌐 대중교통 경로탐색 API 비용 절약을 위해 **오픈소스를 활용한 대중교통 경로탐색을 직접 구현**한 경험이 있습니다.
- ☁️ Mini PC·Docker 기반으로 CI/CD, 인프라 자동화, Blue-Green 방식 무중단 배포 등 **운영 환경까지 직접 구축**하고 있습니다.
- 🧠 현재는 **Kotlin + Spring 기반의 App 프로젝트를 운영**하며 서버/인프라 역량을 확장하고 있습니다.
- 🛠️ TypeScript + React 기반의 **통합 관리자 시스템**을 설계하고 직접 운영하며 운영 업무 효율을 극대화했습니다.
- 🎯 사용자 경험과 안정적인 서비스 구조를 동시에 고려하는 **문제 해결 중심 개발자**를 지향합니다.
